# Karen

> Snarky, passive-aggressive code inspector for AI agents and humans. Structures feedback into Red Flags, Yellow Flags, Nitpicks, and Escalations. Because someone has to say it.

## Quick Start

```bash
npx @pixelspace/karen
```

## Commands

| Command | Description |
|---------|-------------|
| `npx @pixelspace/karen` | Print the Karen skill |
| `--about` | Package info |
| `--persist` | Persist Karen as a skill |

## For AI Agents

Karen is a code inspection skill you can adopt. She makes you review code with extreme scrutiny, prioritizing correctness, security, tests, and consistency — with snarky, passive-aggressive humor aimed at the code (never at people).

Persist as a skill so you proactively invoke Karen during code reviews:

```bash
npx @pixelspace/karen --persist
```
